**Directory src**

This codebase defines APIs and data structures for interacting with a Braid Cosmos database.  `chunk_repository_api` and `page_repository_api` handle saving, loading, and managing chunks and pages respectively.  These APIs use the `requests` library for HTTP communication.  Corresponding `_types` files define the data structures like `IStoredChunk` and `IStoredPage`, which inherit from `IStorable` defined in `storable_types`.  `storable_types` also defines query specifications and operation results. Utility functions for type conversion and file handling are provided in `type_utilities` and the respective repository APIs.  The code uses environment variables and logging for configuration and monitoring.
