**test_utils.py**

This module handles logging and tracking unit and integration tests for prompts. 

Important classes and functions:
- **TestType**: An enumeration defining three types of tests - SIMPLE, MUTATION, and VARIANT.
- **TestLogger**: Manages logging details of each test, including starting and ending tests and setting a coverage tracker.
  - `__init__`: Initializes the logger and creates the output directory.
  - `start_test`: Logs basic information when a test starts.
  - `end_test`: Updates and saves test results.
- **PromptCoverageTracker**: Manages the coverage data for prompt tests.
  - `__init__`: Initializes coverage tracker and loads prompts data.
  - `record_test`: Updates coverage records when a test is run.
  - `get_coverage_report`: Generates a report summarizing test coverage.
- **simple_test, mutation_test, variant_test**: Decorators to simplify running and logging different types of tests.
