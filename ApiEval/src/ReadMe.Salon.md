**test_utils.py**

This code defines a testing framework with decorators for different test types and logging capabilities.

**Key Classes and Functions:**
1. **TestType (Enum)**: Defines three types of tests: SIMPLE, MUTATION, and SYSTEM.
2. **TestLogger**: Handles logging for tests. It manages the logs' directory creation, test start/end, and saving results in JSON format.
3. **PromptCoverageTracker**: Manages prompt metadata and tracks test coverage statistics, loading prompt data from JSON files and updating coverage data.
4. **simple_test, mutation_test, variant_test (decorators)**: Function decorators that log the start and end of tests, handle exceptions, and wrap the test functions for specific test types.

**Usage:**
- Decorators can be applied to test functions to automatically log test metadata and results.
- `PromptCoverageTracker` records test runs per prompt and generates coverage reports.

**Important Methods:**
- `TestLogger.start_test` and `end_test`: Manage the start and end of a test, recording relevant data.
- `PromptCoverageTracker.record_test` and `get_coverage_report`: Update test records and generate coverage reports.
