**test_utils.py**

This code implements a testing framework with distinct test types and detailed logging features. 

**Key Classes and Functions:**
1. **TestType (Enum)**: Enumerates three test categories: SIMPLE, MUTATION, and VARIANT.
   
2. **TestLogger**: Manages logging functionality for tests, which includes creating directories for logs, recording start and end times of tests, and saving results in JSON files. Notable methods include `start_test` and `end_test` for managing test execution logs.

3. **PromptCoverageTracker**: Tracks prompt metadata and test coverage statistics. It loads prompt data from JSON files, updates coverage records, and generates reports. Significant methods are `record_test` for updating test history and `get_coverage_report` for generating coverage summaries.

4. **simple_test, mutation_test, variant_test (decorators)**: These decorators mark functions for specific test types, log execution details, and manage exceptions.

**Usage:**
- Apply decorators to test functions for automatic logging and metadata management.
- Use `PromptCoverageTracker` to keep track of test execution per prompt and generate coverage reports.
