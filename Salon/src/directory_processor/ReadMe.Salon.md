This code defines a base class `DirectoryProcessor` for processing directory data. Subclasses must implement the `visit` method to perform specific actions on a `DirectoryData` object.  The `process_directory` function recursively traverses a directory structure represented by `DirectoryData` objects. For each directory, it calls the `visit` method of each provided `DirectoryProcessor`.  Processors can optionally return a file path, which is added to the current directory's `source_files` list. This allows processors to collect files within the directory structure.
