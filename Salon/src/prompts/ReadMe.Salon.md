**prompts.py**

This code defines prompts for generating C4 diagrams (Context, Container, Component) using Mermaid syntax.  Each prompt guides an AI assistant to create valid diagrams by emphasizing correct element usage (`C4Context`, `C4Container`, `C4Component`, `System_Boundary`, `Rel`), referencing components by ID, and avoiding PlantUML syntax.  The prompts prioritize smaller, correct diagrams over larger, error-prone ones.  Additionally, personas are defined for code summarization and C4 diagram generation.
