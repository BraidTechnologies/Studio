**directory_data.py**

The `DirectoryData` class stores metadata about a directory.  It tracks the directory's path, whether it contains a "ReadMe.Salon.md" file, lists of source and all files within the directory, whether a summary is needed for the directory, and a list of `DirectoryData` objects representing subdirectories. This structure allows for recursive representation of directory structures and their associated metadata.  It uses the `pathlib` library for path manipulation and type hinting for clarity.
