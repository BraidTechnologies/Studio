**Directory src**

These Python scripts automate code analysis and documentation. `api_to_test_code.py` generates Pytest code from API specifications in JSON or YAML, using an OpenAI assistant.  `repo_to_c4.py` creates C4 diagrams from a GitHub repository, summarizing code using an API. `repo_to_text.py` processes a local repository, concatenating file contents into text summaries with a specified word limit per file.  All scripts use command-line arguments and helper functions for file processing, API interaction, and output generation.  `repo_to_text.py` leverages NLTK for word counting and manages content summarization based on file type and directory structure.


**Directory test**

This codebase uses `pytest` and `unittest` to test modules related to code summarization and diagram generation.  `test_directory_visitor_c4`, `test_directory_visitor_notebook_lm`, and `test_directory_visitor_readme` test classes that process directories for C4 model generation, language model input preparation, and README generation, respectively.  `test_directory_walker` tests the core directory traversal logic.  `test_model_drivers` tests the abstract `SalonModelDriver` and its concrete implementations.  `test_repo_to_c4` and `test_repo_to_text` test command-line scripts for C4 diagram generation and text extraction from repositories.  Tests cover argument parsing, file handling, error conditions, and integration with external models like Braid API and Local Gemini.  Mocking and temporary files/directories are used extensively for isolation and consistent testing environments.
