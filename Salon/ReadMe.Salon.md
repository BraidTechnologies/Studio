**Directory src**

These Python scripts automate code analysis and documentation. `api_to_test_code.py` generates Pytest code from API specifications (JSON/YAML), leveraging an OpenAI assistant.  `repo_to_c4.py` creates C4 diagrams from GitHub repositories, using an API for code summarization.  `repo_to_text.py` summarizes a repository's code by concatenating file contents into text files, with a configurable word limit per file, using NLTK for word counting and an external API for summarization. All scripts utilize command-line argument parsing and validation.


**Directory test**

These Python tests, using `pytest` and `unittest`, cover various modules of a code analysis and documentation generation system.  `test_directory_visitor_*` files test different visitor classes responsible for generating C4 diagrams, notebook-style text chunks, and README files. They validate file handling, content processing, and model interactions.  `test_directory_walker` ensures correct directory traversal and visitor notification.  `test_model_drivers` verifies the model driver factory and individual driver implementations (Braid API, Local Gemini).  `test_repo_to_c4` and `test_repo_to_text` test the main entry points, focusing on argument parsing, validation, and integration with core modules using mocks for isolation.  Integration tests are present but often skipped by default.
