**Directory BoxerEval**

This code develops a question generation and evaluation system using Azure OpenAI across several versions.  It starts with simple question enrichment and similarity checks, progressively adding persona-based question generation (`PersonaStrategy`), follow-up question evaluation (`GeminiEvaluator`), and better evaluation metrics.  `TestRunner` runs tests, supporting both static and persona-based modes.  Utility modules handle API setup, retries, and storing results.  The code prioritizes modular design, error management, and logging for robustness.


**Directory Salon**

This project automates code analysis and documentation using Python.  The `src` directory contains scripts to generate tests from API specs (`api_to_test_code.py`), create C4 diagrams (`repo_to_c4.py`), and summarize code into text (`repo_to_text.py`).  These scripts use OpenAI and an external API.  The `test` directory holds tests built with `pytest` and `unittest`.  These tests cover directory traversal, C4 model generation, README creation, and text summarization.  Mocking ensures test isolation.  The project uses NLTK for text processing and integrates with Braid API and Local Gemini.


**Directory WaterfallBrowser**

Waterfall Browser displays hierarchical data fetched using a `chunkId`.  The main `App` component uses `ChunkRetriever` to fetch and display data. Depending on the fetch status, `ChunkRetriever` renders a loading, error, or data view (`ChunkView`).  `ChunkView` presents the data and navigation links to related chunks.  The app uses Fluent UI and custom CSS for styling.  `Defusc` decodes an API key, and `reportWebVitals` handles performance tracking.  `UIString` centralizes UI text for easier management.
