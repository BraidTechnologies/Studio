**Directory src**

This React app, Waterfall Browser, fetches and displays hierarchical data chunks.  `App.tsx` sets up the layout and uses `ChunkRetriever.tsx` to fetch data based on a URL parameter.  `ChunkRetriever` displays different components (`ChunkView`, `ChunkViewError`, or `ChunkViewLoading`) based on the retrieval status.  `ChunkView` presents the chunk data with links to parent and related chunks.  Styling uses Fluent UI and custom styles.  `Defusc.tsx` decodes an API key, and `reportWebVitals.ts` handles performance monitoring.  `UIString.ts` centralizes UI text.
