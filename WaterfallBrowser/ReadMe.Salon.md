**Directory src**

This React app, Waterfall Browser, fetches and displays hierarchical data chunks.  `App.tsx` sets up the layout and uses `ChunkRetriever.tsx` to fetch data based on a `chunkId` URL parameter.  `ChunkRetriever` displays loading (`ChunkViewLoading.tsx`), error (`ChunkViewError.tsx`), or data (`ChunkView.tsx`) components conditionally.  `ChunkView` presents the chunk data and links to parent and related chunks. Styling is managed with Fluent UI and custom CSS.  `Defusc.tsx` decodes an API key, and `reportWebVitals.ts` handles performance monitoring.  `UIString.tsx` centralizes UI text.
