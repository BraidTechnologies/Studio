**MakePromptIds.ts**

This code generates TypeScript and Python files containing constant declarations for prompt IDs.  It reads prompt data from JSON files (e.g., `Default.Prompts.json`, `Boxer.Prompts.json`), extracts the `name` and `id` of each prompt, and transforms the names into `camelCase` for TypeScript and `snake_case` for Python.  The generated files provide convenient, type-safe access to prompt IDs, preventing hardcoding and improving code maintainability.  The script automates this process, ensuring the generated IDs stay synchronized with the prompt data.
