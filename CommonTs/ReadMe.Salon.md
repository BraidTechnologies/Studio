**Directory scripts**

This script automates the creation of TypeScript and Python files defining constants for prompt IDs.  It parses prompt data (name and ID) from JSON files like `Default.Prompts.json`. Prompt names are converted to `camelCase` for TypeScript and `snake_case` for Python constants.  Generating these files ensures consistent and type-safe prompt ID usage across codebases, eliminating hardcoded IDs and simplifying maintenance.  The script automatically updates the generated code to reflect any changes in the prompt data files.


**Directory src**

This codebase provides a suite of APIs for interacting with Braid's AI services.  Modules like `ActivityRepositoryApi`, `ChunkRepositoryApi`, and `PageRepositoryApi` offer CRUD operations for managing activities, text chunks, and pages, respectively.  Authentication via session keys is managed by the `Api` base class and the `SessionApi`.  `Model` and `ModelDrivers.OAI` handle model selection and interaction with OpenAI's embedding and chat services.  Several modules define types for requests and responses, ensuring type safety.  Utility modules like `Asserts`, `Compress`, and `Logging` provide helper functions.  Environment configurations are managed by the `Environment` and `IEnvironmentFactory` modules.  The `Fluid` modules handle integration with Microsoft Fluid Framework.  Finally, the `IPromptPersona` and `IPromptPersonaFactory` modules manage various AI personas for different tasks.


**Directory test**

These test files validate core components of an AI interaction system.  `chatdriver.test.ts` ensures chat models respond correctly to prompts with different providers and conversation histories. `chunkdriver.test.ts` verifies text splitting for large inputs.  `embeddriver.test.ts` checks that embedding models generate valid vector representations of text. Lastly, `promptrepository.test.ts` confirms the system loads and manages various prompt templates, including placeholder replacement for dynamic content.  All tests leverage Mocha and Expect for assertions and asynchronous operation handling.
